# F1race

Браузерная аркадная игра по Формуле-1 (RPG + онлайн-аркада). Текущая стадия: **single-player с авторитетным сервером** — вся симуляция (квалификация + гонка) считается на сервере и раздаётся клиентам по WebSocket; браузер только рендерит. Создание пилота, live-квалификация (выезд из боксов с интервалом, круг прогрева, боевой круг) и гонка с управлением пит-стопами.

## Архитектура
- **`packages/race-engine`** — чистая TS-библиотека без I/O: `RaceEngine` (гонка) и `QualifyingEngine` (квалификация). Все формулы/баланс — в `src/config.ts`. Не зависит от DOM/Node.
- **`apps/server`** — Node + WebSocket: `GameSession` авторитетно крутит квалу → гонку в реальном времени и раздаёт `snapshot()`. Принимает команды (`hello`, `pit`, `speed`, `pause`, `restart`).
- **`apps/web`** — Vite + React + Canvas: подключается по WS, рендерит снапшот, отправляет команды. Никакой игровой логики на клиенте.

## Запуск локально

Node ≥ 20, pnpm ≥ 10. Понадобятся два терминала (сервер + клиент).

```bash
pnpm install
pnpm --filter @f1race/race-engine build   # собрать dist (нужно серверу)

# терминал 1 — сервер (ws://localhost:8787)
pnpm --filter @f1race/server dev

# терминал 2 — клиент (http://localhost:5173)
pnpm --filter @f1race/web dev
```

Адрес WS задаётся через `VITE_WS_URL` (по умолчанию `ws://localhost:8787`) — создайте `apps/web/.env.local` при другом хосте.

## Игровой цикл
1. Экран **«Создание пилота»**: имя, страна, распределение 10 очков по 6 навыкам, команда, стартовая резина.
2. **Квалификация** (симуляция, без кнопок): машины выезжают из боксов с интервалом 5 c, проходят круг прогрева и боевой круг — лучшее время определяет стартовую решётку.
3. **Гонка** (Red Bull Ring, число кругов по дистанции ~85 км): top-down вид, пит-стоп с обязательной сменой состава (правило Ф1), потеря ≈20 c, андеркот, «поезда» и синие флаги для круговых.
4. Пауза и ускорение (2×/6×/12×/24×), рестарт, смена пилота, итоговая таблица.

```bash

```

## Структура

```
packages/race-engine/src
  config.ts      все константы-формулы (темп, шины, бой, старт, XP, дивизионы)
  engine.ts      RaceEngine: real-time шаги, пит-стопы, обгоны, snapshot()
  formula.ts     формулы темпа, износа, шанса обгона, старта
  tyres.ts       составы шин, сцепление, износ
  track.ts       трассы (Red Bull Ring), 2D-путь для рендера
  skills.ts      навыки и валидация распределения
  qualifying.ts  квалификация
  factory.ts     сборка драйверов/ботов и RaceConfig

apps/web/src
  App.tsx               переключение стадий (setup ↔ race)
  race/SetupScreen.tsx  создание пилота
  race/RaceView.tsx     экран гонки
  race/TrackCanvas.tsx  canvas-рендер трассы и машин
  race/useRaceEngine.ts хук: движок + requestAnimationFrame + пит-команды
  race/PitPanel.tsx, Telemetry.tsx, Standings.tsx, colors.ts
```

## Архитектурные заметки
- Все вычисления, влияющие на результат (формулы), — в `race-engine`, клиент только рендерит. Это закладка под онлайн: серверная авторитетная симуляция, клиент — отображение.
- Модель гонки — real-time по `dt`-тикам (сейчас 0.1 c), клиент продвигает по N шагов за кадр в зависимости от множителя скорости.
