# F1race

Браузерная аркадная игра по Формуле-1 (RPG + онлайн-аркада). Текущая стадия: **однопользовательский режим без регистрации** — создание пилота и live-просмотр гонки с управлением пит-стопами.

## Стек
- **Язык:** TypeScript (strict).
- **Симуляция:** `packages/race-engine` — детерминированный real-time движок (dt-тики), чистая логика без I/O. Все формулы вынесены в `src/config.ts` как точки тюнинга.
- **Клиент:** `apps/web` — Vite + React + Canvas (PWA-ready, дальше переиспользуется для мобилок).

## Запуск локально

Требуется Node ≥ 20 и pnpm ≥ 10.

```bash
pnpm install                 # установка зависимостей
pnpm --filter @f1race/web dev   # дев-сервер: http://localhost:5173
```

Откроется экран **создания пилота**: имя, страна, распределение 10 очков по 6 навыкам, выбор команды и стартовой резины. Кнопка «На стартовую решётку» запускает гонку.

## Что есть в гонке
- Квалификация (по навыку «Пилотирование») → стартовая решётка.
- Реальное время: машинки едут по трассе Red Bull Ring, верхний вид.
- **Пит-стоп** (панель справа): выбор резины Soft/Medium/Hard, обязательный минимум один. Потеря ≈22 c, эффект **андерката** — естественный.
- «Поезда»: машина с сильной защитой удерживает позицию от слабого атакующего, пока разница темпа не станет критической.
- Пауза и ускорение (1×/4×/8×/20×), рестарт, смена пилота.
- Итоговая таблица топ-10 с местами, временем и быстрейшим кругом.

## Полезные скрипты

```bash
pnpm --filter @f1race/race-engine test        # юнит-тесты движка (27)
pnpm --filter @f1race/race-engine sim         # прогон гонки в консоли (лог/тюнинг)
pnpm --filter @f1race/race-engine sim:grid    # сравнение билдов навыков героя
pnpm --filter @f1race/race-engine typecheck   # проверки типов движка
pnpm --filter @f1race/web build               # прод-сборка клиента
```

## Структура

```
packages/race-engine/src
  config.ts      все константы-формулы (темп, шины, бой, старт, XP, дивизионы)
  engine.ts      RaceEngine: real-time шаги, пит-стопы, обгоны, snapshot()
  formula.ts     формулы темпа, износа, шанса обгона, старта
  tyres.ts       составы шин, сцепление, износ
  track.ts       трассы (Red Bull Ring), 2D-путь для рендера
  skills.ts      навыки и валидация распределения
  qualifying.ts  квалификация
  factory.ts     сборка драйверов/ботов и RaceConfig

apps/web/src
  App.tsx               переключение стадий (setup ↔ race)
  race/SetupScreen.tsx  создание пилота
  race/RaceView.tsx     экран гонки
  race/TrackCanvas.tsx  canvas-рендер трассы и машин
  race/useRaceEngine.ts хук: движок + requestAnimationFrame + пит-команды
  race/PitPanel.tsx, Telemetry.tsx, Standings.tsx, colors.ts
```

## Архитектурные заметки
- Все вычисления, влияющие на результат (формулы), — в `race-engine`, клиент только рендерит. Это закладка под онлайн: серверная авторитетная симуляция, клиент — отображение.
- Модель гонки — real-time по `dt`-тикам (сейчас 0.1 c), клиент продвигает по N шагов за кадр в зависимости от множителя скорости.
